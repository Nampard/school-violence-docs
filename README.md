# 학교폭력 행정서류 생성 스킬 (school-violence-docs)

학교폭력 사안 처리 흐름에 따라 **실제 내용을 채운** 한글(hwpx) 행정문서를 생성하는 AI 스킬입니다.
빈 양식을 나눠주는 것이 아니라, 담당자가 두서없이 설명한 사안 정황을 양식의 정확한 칸에 채워 출력합니다.
채우기 어려운 칸은 비워 두므로, 담당자는 아래아한글에서 빈칸만 마무리하면 됩니다.

> ⚠️ **적용 범위**
> - 본 스킬의 서식은 **충청북도교육청 기준**입니다.
> - **다른 시·도 교육청 서식은 추후 도입 예정**입니다. (교육청마다 서식이 달라 셀 주소·체크박스 매핑을 새로 맞춰야 합니다.)

---

## 무엇을 하나

다음 서류를 실제 사안 내용으로 채워 생성합니다.

**붙임 서류**
1. **학교폭력 사안접수 보고서**
2. **학교폭력 전담기구 심의결과 보고서**
3. **학교장 자체해결·종결 결과 보고서(통합)**
4. **학교장 자체해결 / 종결 동의서** (피해관련 학생·보호자 서명용)

**공문(기안문) 6종** — 위 붙임을 보내는 결재·발송 문서
5. 사안접수 보고 · 전담기구 심의 **개최** · 전담기구 심의 **결과 보고** · 자체해결(종결) 결과 보고 **[내부결재]** · 자체해결(종결) 결과 보고 **[교육지원청]** · **심의위원회 개최 요청**

> 결과 보고 공문 2종은 **자체해결용·종결용 문구가 따로** 제공되어(`자체해결내부`/`자체해결청`/`종결내부`/`종결청`) 실제로는 8가지 종류입니다. 종결 사안에 "자체해결"이라는 제목이 남지 않습니다.

### 두 가지 흐름
- **흐름 ① — 사안접수**: 사안 정황을 입력하면 사안접수 보고서를 생성.
- **흐름 ② — 사안조사 이후 분기**: 사안조사 보고서를 제시하면, 간단한 확인을 거쳐 분기별 서류를 생성.
  - **자체해결** (4요건 충족 + 피해측 동의) → 전담기구 보고 + 자체해결 결과 보고 + **자체해결 동의서**(피해측 서명)
  - **종결** (학교폭력 아님·오인신고 등) → 전담기구 보고 + 종결 결과 보고 + **종결 동의서**(피해측 서명)
  - **심의위 이송** (요건 미충족 또는 동의 미제출) → 전담기구 보고 + 심의위원회 개최 요청

각 단계에는 붙임을 보내는 **공문(기안문)** 이 함께 생성됩니다. 분기와 무관하게 `개최`·`결과` 공문을 만들고, 자체해결이면 `자체해결내부`+`자체해결청`, 종결이면 `종결내부`+`종결청`, 심의위 이송이면 `심의위`(개최 요청)를 더합니다. **hwpx 파일과 NEIS 복붙용 텍스트를 함께** 출력하므로, 나이스 기안창에 그대로 붙여넣을 수 있습니다.

### 핵심 원칙
- **빈칸 원칙**: 모르거나 불확실한 값은 추측하지 않고 빈칸으로 둔다(한글에서 직접 채움). 법적 분류(피해유형·자체해결 요건 등)는 지시가 있을 때만 채운다.
- **생성 전 1회 확인**: 곧바로 만들지 않고 핵심 항목(접수일시·신고자·피해유형·즉시분리 여부)을 한 번에 모아 확인한 뒤 생성.
- **행정문체·분량**: 자유서술 칸(사안 내용)은 최소 500자 이상, 명사형 종결어미(~음/~함)로 작성. 사실을 지어내지 않고 육하원칙으로 상술하되, 분량이 부족하면 부족한 사실관계를 추가로 확인해 보강.
- **동의서는 완곡하게**: 피해 학생·보호자가 읽고 서명하는 자체해결/종결 동의서의 사안 내용은 사실을 따르되 **완곡·객관적 표현으로 500자 내외**(자극적 묘사 금지, 2차 가해 방지).
- **글자 겹침 방지·관련학생 행 자동 복제** 등 한글 양식 채움의 까다로운 부분을 자동 처리.

## 설치 및 사용

먼저 저장소를 받습니다.

```bash
git clone https://github.com/Nampard/school-violence-docs.git
```

### 1) Claude Code (CLI · 데스크톱 앱)

스킬 디렉토리를 개인 스킬 폴더에 복사하면 됩니다.

```bash
cp -r school-violence-docs/skills/school-violence-docs ~/.claude/skills/
# 또는 패키지로:  unzip school-violence-docs/school-violence-docs.skill -d ~/.claude/skills/
```

설치 후 대화창에 **"학폭 사안접수서 만들어줘"**, **"이 조사보고서로 자체해결 서류 뽑아줘"** 처럼 요청하면 스킬이 자동으로 트리거됩니다. (kordoc MCP·lxml 사전 점검 후 진행)

### 2) Cowork

Cowork도 동일한 Agent Skills 형식을 지원합니다. `skills/school-violence-docs/` 폴더(또는 `.skill` 패키지)를 Cowork의 스킬로 추가하고, **kordoc MCP를 연결**하고 **lxml이 설치**돼 있으면 Claude Code와 동일하게 자동 트리거됩니다. 자연어로 사안을 설명하면 같은 흐름으로 문서를 생성합니다.

### 3) Codex · 일반 터미널

Codex는 `.skill` 자동 트리거를 지원하지 않습니다. 대신 **`skills/school-violence-docs/README.md`(직접 실행 가이드)** 를 읽히고 스크립트를 직접 호출하면 동일하게 동작합니다(채움 엔진은 순수 Python이라 Claude 의존성이 없습니다).

```bash
cd school-violence-docs/skills/school-violence-docs/scripts
python3 fill_jeopsu.py      ../assets/templates/사안접수_빈양식.hwpx        data.json  out.hwpx
python3 fill_jeondamgigu.py ../assets/templates/전담기구심의_빈양식.hwpx    data.json  out.hwpx
python3 fill_result.py      ../assets/templates/자체해결종결_빈양식.hwpx    data.json  out.hwpx
python3 fill_donguiseo.py   ../assets/templates/자체해결동의서_빈양식.hwpx  data.json  out.hwpx
python3 fill_gongmun.py     ../assets/templates/공문_빈양식.hwpx           data.json  out.hwpx
```

`data.json` 스키마·예시는 [skills/school-violence-docs/README.md](skills/school-violence-docs/README.md)를 참고하세요.

## 사용법 — 분기별 예시 (처음 쓰는 분을 위해)

Claude Code나 Cowork에서는 **파일을 만들 필요 없이 채팅으로 말하면** 됩니다.
아래는 실제 사용 장면을 그대로 옮긴 것입니다. (터미널에서 직접 실행하려면 [스킬 실행 가이드](skills/school-violence-docs/README.md)를 보세요.)

### 전체 흐름 한눈에

```
① 사안접수  ──▶  ② 전담기구 심의  ──┬──▶  자체해결   (4요건 모두 O  +  피해측 동의 O)
                                      ├──▶  종결       (조사 결과 학교폭력이 아님)
                                      └──▶  심의위 요청 (4요건 중 X  또는  동의 미제출)
```

단계마다 **붙임 서류 + 그걸 보내는 공문**이 함께 나옵니다. 공문은 hwpx 파일과 **NEIS에 붙여넣을 텍스트**로 같이 출력됩니다.

---

### 분기 1. 사안접수 — 신고가 막 들어왔을 때

**💬 이렇게 입력하세요** — 형식 없이 아는 대로 편하게 쓰면 됩니다.

> 오늘 아침 9시쯤 1학년 3반 홍길동이랑 김철수가 복도에서 말다툼하다가 서로 부모 욕을 하고 머리채를 잡았대요.
> 둘 다 서로 학폭으로 신고했고, 10시에 상호 2호조치 했고 학부모한테도 그때 유선으로 통보했어요. 사안번호는 3호입니다.

**🤖 이렇게 한 번만 되묻습니다**

> 접수일시 · 신고자 · 피해유형 · 즉시분리 여부를 알려주실 수 있나요?
> (모르면 비워두세요 — 빈칸으로 생성되어 아래아한글에서 채우시면 됩니다)

답하지 않은 항목은 **추측하지 않고 빈칸**으로 둡니다. 억지로 채워 틀린 내용이 들어가는 걸 막기 위해서입니다.

**📄 나오는 것**

| 파일 | 용도 |
|---|---|
| 학교폭력 사안접수 보고서 (hwpx) | 공문의 **붙임** |
| 사안접수 보고 **공문** (hwpx + NEIS 텍스트) | 교육지원청 발송용 |

**✍️ 그 다음 할 일**
1. hwpx를 아래아한글로 열어 **빈칸을 채웁니다** (교감·담당자 연락처처럼 학교마다 다른 항목은 비워 둡니다)
2. NEIS에서 새 기안 → 화면에 출력된 **공문 텍스트를 그대로 붙여넣고** 보고서를 붙임으로 첨부
3. 교육지원청으로 발송 (접수 후 48시간 이내)

---

### 분기 2. 자체해결 / 종결 — 조사가 끝났을 때

교육청 조사관이 준 **사안조사 보고서를 그대로 던져주면** 됩니다(hwp/hwpx 모두 읽습니다).

**💬 이렇게 입력하세요**

> (사안조사 보고서 파일 첨부) 이거 자체해결로 서류 만들어주세요.

**🤖 이렇게 되묻습니다** — 조사보고서에 없는 것만 물어봅니다.

> 전담기구 심의 일시와 참석자를 알려주세요.
> (4요건·동의 여부는 조사보고서에서 읽었습니다 — 4요건 모두 충족, 피해측 동의 확인)

**📄 나오는 것** (자체해결 기준. 종결이면 '종결' 문서로 나옵니다)

| 구분 | 파일 |
|---|---|
| 붙임 | 전담기구 심의결과 보고서 |
| 붙임 | 학교장 자체해결 결과 보고서 |
| 붙임 | **자체해결 동의서** (피해·가해 학생 모두 기재, 서명은 피해측) |
| 공문 | ② 전담기구 심의 **개최** (내부결재) |
| 공문 | ③ 전담기구 심의 **결과 보고** (내부결재) |
| 공문 | ④ 자체해결 결과 보고 **[내부결재]** |
| 공문 | ⑤ 자체해결 결과 보고 **[교육지원청]** |

> **종결(학교폭력이 아닌 경우)** 도 똑같이 4건이 나오되 제목·본문이 전부 '**종결**'로 바뀝니다.
> 종결 사유는 3가지 중 고릅니다 — ①제3자 신고 오인 ②의심사안 불성립 ③**피해학생 본인이 오인신고였음을 인정**.

**✍️ 실무 순서가 중요합니다**

공문은 만들어진 순서대로 기안하는 게 아니라 **실제 일정에 맞춰** 올립니다.

```
② 개최 공문 기안  →  (전담기구 심의 실시)  →  ③ 결과 보고 공문  →  ④ 내부결재  →  ⑤ 교육지원청 보고
```

각 공문의 「관련」 항목에는 **앞 공문의 기안번호**를 적어야 합니다. 이 번호는 NEIS에서 기안해야 생기므로,
스킬은 그 자리를 `○○○○학교-0000(20○○.00.00.)` 로 비워 둡니다. 기안하실 때 직접 채우시면 됩니다.

---

### 분기 3. 심의위원회 요청 — 자체해결이 안 될 때

4요건 중 하나라도 미충족이거나, **피해측이 자체해결에 동의하지 않으면** 심의위원회로 넘깁니다.

**💬 이렇게 입력하세요**

> (사안조사 보고서 첨부) 피해학생이 자체해결에 동의를 안 했어요. 심의위 요청 서류 만들어주세요.

**🤖 이렇게 되묻습니다**

> 전담기구 심의 일시·참석자와, 심의위 요청서에 넣을 **관련학생 생년월일**을 알려주세요.
> 가해관련 학생 중 **학생선수**가 있으면 함께 알려주세요. (모르면 빈칸으로 둡니다)

> 💡 심의위 요청서에는 **생년월일·학생선수 여부**가 들어갑니다. 다른 서류엔 없는 항목이라 따로 확인합니다.

**📄 나오는 것**

| 구분 | 파일 |
|---|---|
| 붙임 | 전담기구 심의결과 보고서 (결정사항에 "심의위원회 심의 요청" 기재) |
| 공문 | ② 전담기구 심의 **개최** / ③ 심의 **결과 보고** |
| 공문 | ⑥ **심의위원회 개최 요청** (관련학생 표 포함) |

> **주의**: 심의위 이송일 때는 4요건·동의 칸을 **함부로 X로 찍지 않습니다.**
> "어느 요건이 미충족인지" 확인된 것만 채우고 나머지는 빈칸으로 둡니다. 법적 판단이 걸린 칸이기 때문입니다.

**✍️ 붙임 10종은 직접 확인하세요**

심의위 요청 공문의 붙임 목록에는 `※ 해당 경우만` 조건부 항목이 많습니다(학생선수 서류, 아동심리 전문가 의견서 등).
누락 위험이 커서 스킬이 임의로 지우지 않으니, **해당 없는 항목은 한글에서 직접 지우시면** 됩니다.

| 궁금한 점 | 답 |
|---|---|

| 동의서 문구가 딱딱하지 않나? | 동의서는 피해 학생·보호자가 읽고 서명하므로 **자극적 표현을 피해** 완곡하게 씁니다. |
